## 七、残余风险

| 优先级 | 风险 | 处理路径 |
| --- | --- | --- |
| 中 | `public/audio/music/*.mp3` 来源字段乱码且授权证据不足 | 当前个人自用构建默认保留并加载本地 MP3；如未来公开传播，建议替换为自有 / 可授权 / 可署名音频 |
| 中 | GitHub Pages 静态包可能带出 raw PNG、source sheet、legacy 和授权未确认素材 | `build:public` 已裁剪这些目录 / 文件；后续 GitHub Pages 工作流应调用 `npm run build:public` 而不是普通 build |
| 中 | Next 内置 PostCSS advisory | 等待 Next 安全补丁或兼容升级；不要使用 `npm audit fix --force` 降级 Next |
| 中 | 角色图公开传播授权与署名 | 当前个人自用构建默认保留本地角色图；如未来公开传播，需逐项确认授权、署名和来源链接 |
| 中 | 严格 CSP 尚未启用 | 公开域名和资源清单稳定后再配置 CSP，并回归图片、字体、音频和 Next 运行脚本 |
